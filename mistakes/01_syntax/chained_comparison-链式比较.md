# 链式比较 (Chained Comparison)

## 🧠 我的“错误脑回路”

我老觉得 `a < b < c` 会先算出 `a < b` 是 True 还是 False，然后用布尔值和 `c` 比较。或者觉得它只能从左往右依次比较大小,结果是表达式的数值，而不是**布尔值**

## ✅ 正确的“底层逻辑”

Python 的链式比较本质上就是 **`and` 逻辑连接**，且最后结果是布尔值。
`a < b < c` 等价于 `a < b and b < c`。**关键点**：中间的 `b` 只在内存中计算一次（但在基础使用中可以忽略这点）。
特别坑的是：`a < b > c` 在 Python 中是合法的！它等价于 `a < b and b > c`（即判断 `b` 是否同时大于 `a` 和 `c`）。

## 💻 救命代码

```python
# 示例 1：常见的数值区间判断
x = 5
if 1 < x < 10:   # 优雅写法，不用写 x > 1 and x < 10
    print("在区间内")

# 示例 2：打破常规思维（非传递性）
print(3 < 4 > 2)   # True，因为 3<4 且 4>2
print(3 < 4 < 2)   # False，因为 3<4 且 4<2 (不成立)

# 示例 3：注意等号的方向
print(1 == 2 == 2) # False，1==2 且 2==2，第一个就不成立
```

## 🔗 记忆锚点（联想法/生活比喻）

把 `a < b < c` 看成数学课本上的写法，中间的那个 `b` 是“双面胶”，既要和左边比，又要和右边比。
