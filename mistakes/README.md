## 📝 使用指南

### 新增一条错题

1. 复制 [`template.md`](./template.md) 到对应分类文件夹。
2. 重命名为 `简短英文名-中文名.md`（如 `chained_comparison-链式比较.md`）。
3. 填写 5 个核心字段：错误脑回路 → 正确逻辑 → 救命代码 → 记忆锚点 → 关联题目。
4. 更新本页面的“当前战况”统计和“快速索引”表格。

### 复习一条错题

- **状态流转**：`🔴 待攻克` → `🟡 已理解，仍需复习` → `🟢 已掌握，可归档`
- 当某条错题达到 🟢 状态后，可移至 `archived/` 子文件夹，保持主目录清爽。

### 什么时候记？
- 写代码报错排查超过 **5 分钟**才解决 → 记！
- 看题解第一遍没看懂 → 记！
- 感觉“这次懂了但下次可能忘” → 记！
