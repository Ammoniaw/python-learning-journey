### 6.  请问下面代码为什么会出错？如何解决呢？

- 代码

  ```python
  >>> a, b, c = "FishC"
  Traceback (most recent call last):
    File "<pyshell#3>", line 1, in <module>
      a, b, c = "FishC"
  ValueError: too many values to unpack (expected 3)
  ```

- `ValueError`：值异常，提示解包的值很多，但是变量只有三个

- 可以使用`*`

  ```python
  >>> a, b, *c = "FishC"
  >>> a
  'F'
  >>> b
  'i'
  >>> c
  ['s', 'h', 'C']
  ```

### 0. 使用timeit模块测试Python创建列表、元组那个更快？

- 代码实现

  > 课后作业似乎看起来更简单了，终于没有那么多算法了。

  ```python
  # -*- coding: utf-8 -*-
  # @Software: PyCharm
  # @Author: Ammoniaw
  # @FileName: times.py
  # @Date: 2026/8/9
  # @Description: 使用timeit模块
  import timeit
  
  # 测试创建列表的时间
  test_list = timeit.repeat('x = ["123"]', repeat=100)
  # 测试创建元组的时间
  test_tuple = timeit.repeat('x = ("123")', repeat=100)
  
  result_list = sum(test_list) / 100  # 小甲鱼使用len()来计算100，也很可以，今后要多注意使用内置函数了
  result_tuple = sum(test_tuple) / 100
  print(f"{result_list=}, {result_tuple=}")
  
  # result_list=0.04046112099953461, result_tuple=0.020012311001773923,似乎是元组更快
  ```
