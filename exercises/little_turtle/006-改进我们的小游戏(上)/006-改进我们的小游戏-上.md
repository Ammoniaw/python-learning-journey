### 1. 请问下面代码会打印多少个 "Yo~"？

- 代码

  ```python
  yoo = 222
  while yoo < 233:
      print("Yo~")
  ```

- 无数个，因为while循环的条件始终为True,循环会无限循环下去。

### 2. 请问下面代码会打印多少个 "Man"？

- 代码

  ```python
  while 1 + 1 == 2:
      print("Man")
  ```

- 无数个，因为while循环的条件判断始终为True

### 3. 请问下面代码存在什么问题？

- 代码

  ```python
  age = input("请输入你的年龄：")
  
  if age <= 18:
      print("你已经成年^o^")
  else:
      print("对不起，你还未成年T_T")
  ```

- 语法错误：`input()`函数获取的是字符串，如果要使用获取的数值，需要再使用`int()/float()`进行数值类型转换。
- 语义错误：**age >= 18,**才是成年。

### 4. 下面代码是一个死循环（永远不会结束），请添加一个语句，使其打印一遍 "iloveFishC.com" 后退出循环。

- 代码

  ```python
  while True:
      print("iloveFishC.com")
  ```

- 添加`break`语句即可 终止循环

  ```python
  while True:
      print("iloveFishC.com")
      break
  ```

### 0. 编写一个成绩评级程序，要求用户输入分数，程序返回对应的评级

- 要求
  - 分数 < 60，D
  - 60 <= 分数 < 80，C
  - 80 <= 分数 < 90，B
  - 90 <= 分数 < 100，A
  - 分数 == 100，S

- score.py

  ```python
  # -*- coding: utf-8 -*-
  # @Software: PyCharm
  # @Author: Ammoniaw
  # @FileName: score.py
  # @Date: 2026/8/2
  # @Description: 成绩评级程序
  prompt = "请输入您的分数: "
  score = int(input(prompt))
  
  if score == 100:
      print("S")
  elif score >= 90:
      print("A")
  elif score >= 80:
      print("B")
  elif score >= 60:
      print("C")
  else:
      print("D")
  ```

### 1. 修改上一题的代码，让程序可以不断接收输入，直至用户输入小写字母 e 结束程序

- score_stop.py

  ```python
  # -*- coding: utf-8 -*-
  # @Software: PyCharm
  # @Author: Ammoniaw
  # @FileName: score_stop.py
  # @Date: 2026/8/2
  # @Description: 为score.py添加循环，与结束循环条件
  
  while True:
      prompt = "请输入您的分数: "
      score = input(prompt)
      if score == 'e':
          break
      score = int(score)
      if score == 100:
          print("S")
      elif score >= 90:
          print("A")
      elif score >= 80:
          print("B")
      elif score >= 60:
          print("C")
      else:
          print("D")
  ```

- 小甲鱼

  ```python
  score = input("请输入你的分数：")
  
  while score != 'e':  # 把e作为进入while循环的判断条件，如果是e,程序直接结束
      score = int(score)
  
      if score < 60:
          print("D")
  
      if 60 <= score < 80:
          print("C")
  
      if 80 <= score < 90:
          print("B")
  
      if 90 <= score < 100:
          print("A")
  
      if score == 100:
          print("S")
  
      score = input("请输入你的分数：")
  ```
