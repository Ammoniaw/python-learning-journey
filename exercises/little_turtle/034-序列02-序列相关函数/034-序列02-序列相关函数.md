### 0. 列表的 sort() 方法和 sorted() 函数有哪些异同点（至少各举 3 个）？

- 相同点

  - 都可以对列表进行排序，且是升序排序
  - 可以传入reverse，key参数指定自定义排序规则
  - 排序的结果都是列表 - 小甲鱼
  - 都是稳定排序（就是说如果存在多个相同的元素，经过排序之后，这些元素的相对次序保持不变) - 小甲鱼

- 不同点

  - sort()适用范围更加广，不仅限于列表这一种数据类型
  - sorted()不会修改原列表，调用后返回新列表，而sort()方法会修改原列表。
  - 列表的 sort() 方法返回值是 None；sorted() 函数返回一个新列表  - 小甲鱼

### 0. 给定一个整数列表，请编程来调整该列表中整数的顺序，使得所有奇数排好序后放在数组的前半部分，所有偶数排好序后放在数组的后半部分。

- 示例：比如给定的整数列表是 `[1, 8, 7, 3, 6, 5, 4, 2]`，那么调整后的结果应该是 `[1, 3, 5, 7, 2, 4, 6, 8]`

- 代码实现

  > 初步想法：首先排个序，然后分别筛选偶数、奇数列表，随后使用+进行组合即可

  ```python
  nums = [1, 8, 7, 3, 6, 5, 4, 2]
      
  odds = []
  evens = []
  result = []
      
  for each in nums:
      if each % 2 != 0:
          odds.append(each)
      else:
          evens.append(each)
      
  odds.sort()
  evens.sort()
      
  result = odds + evens
  print(result)
  ```

### 1.翻转单词顺序。

- 说明

  ```python
  """
  用户输入一个英文句子，请编程翻转句子中单词的顺序，但单词内字符的顺序不变。为简单起见，标点符号和普通字母一样处理
  
  例如输入字符串是 "I love FishC."，则输出 "FishC. love I"
  
  注意1：用户输入的字符串可能会在前面或者后面包含任意数量的空格，但是反转后的结果将会去除这些空格（例如输入字符串是 "   I love FishC.   "，结果依然输出 "FishC. love I"）
  
  注意2：用户输入的字符串中，单词之间可能不止一个空格，但是反转后的结果将统一使用一个空格作为单词之间的间隔（例如输入字符串是 "I   love        FishC."，结果依然输出 "FishC. love I"）
  """
  ```

- 代码实现

  > 看注意似乎首先应该去除字符串两端的空白字符，随后使用split()进行分割，随后逆序输出整个字符串。

  ```python
  s = input("请输入一个英文句子：")
      
  # 删除首尾空格
  s = s.strip() 
      
  # 分割字符串
  strs = s.split()
      
  # 翻转单词列表
  strs.reverse()
      
  # 拼接为字符串并打印结果
  print(' '.join(strs))
  ```

- 一行形式： `print(' '.join(s.strip().split()[::-1]))`
