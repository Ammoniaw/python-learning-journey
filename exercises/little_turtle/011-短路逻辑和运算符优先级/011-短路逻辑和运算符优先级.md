## 问答题

### 0. 请问下面表达式的值是什么？

- 表达式

  ```python
  >>> 3 == not 5
  ```

- ~~False~~
- 报错，not 运算符的优先级比 == 运算符低，所以表达式是先运算 == 的，即先求出 3 == not 的结果，很明显，Python 彼时很懵逼，python无法进行这样的判断。

### 3. 请问下面表达式的值是什么？

- 表达式

  ```python
  >>> 0 and not 1 or not 2 and 3 or 4 and not 5
  ```

- 结果为 4

  ```python
  >>> 0 and not 1 or not 2 and 3 or 4 and not 5
  # 首先计算所有not - not优先级最高 然后是and 最后是or
  0 and False or False and 3 or 4 and False
  ```

  steps = 7
  i = 1
  flag = False
  
  while i < 10000:
      if (i % 2 == 1) and (i % 3 == 2) \
              and (i % 5 == 4) and (i % 6 == 5) \
              and (i % 7 == 0):
          flag = True
          break
      else:
          steps = i + 1
      i = i + 1
  
  if flag:
      print('阶梯数是：', steps)
  else:

- 小甲鱼的解决方式 - 妙啊

  ```python
  # 作者：小甲鱼
  # 来源：https://fishc.com.cn/thread-150254-1-1.html
  # 本代码著作权归作者所有，禁止商业或非商业转载，仅供个人学习使用，违者必究！
  # Copyright (c) 2020 fishc.com.cn All rights reserved
  
  # 由于目标值必须是能被7整除，所以我们将测试每个7的倍数
  steps = 7
  i = 1
  FIND = False
  
  while i < 100:
      # 由于测试的都是7的倍数 
      # 因此只要同时满足除以2余1、除以3余2、除以5余4、除以6余5，就是最终的结果
      if (steps % 2 == 1) and (steps % 3 == 2) and (steps % 5 == 4) and (steps % 6 == 5):
          FIND = True
          break
      else:
          steps = 7 * (i + 1)
      i = i + 1
  
  if FIND == True:
      print('阶梯数是：', steps)
  else:
      print('在程序限定的范围内找不到答案！')
  ```
