### 0. 请问 6 / 2 的结果是一个整数还是浮点数呢？

- 浮点数，python的除法总是生成浮点数

### 1.请问为什么会出现下面的计算结果：

- 代码

  ```python
  >>> 0.1 + 0.2 - 0.2
  0.10000000000000003
  ```

- 是因为计算机采用2进制存储数字的原因，会产生误差。

### 2. 凭借自己的聪明才智，你觉得为什么浮点数的存储会存在“误差”？

- 比如说无限小数，计算机的内存或者存储空间是有限的，它无法存储这么多位的数字。

### 3.请问下面代码存在什么问题？

- 代码

  ```python
  >>> age = 18
  >>> message = "祝小甲鱼" + age + "岁生日快乐^o^"
  ```

- 不同数据类型之间不能直接拼接。

### 4. 请问在 Python 中，浮点数 1.0 + 2.0 是否等值于整数 3？

- ~~不等于，一个是浮点数，一个是整数，数据类型不同。~~
- 在 Python 中，整数和字符串或者浮点数和字符串是不能进行比较的，但整数和浮点数却可以。另外，**当浮点数相加的结果等于整数时，偏差则不会出现**，比如 0.1 + 0.2 会出现偏差，但 0.1 + 0.2 + 0.7 却能得到整数答案 1.0。

### 0. 表达式 0.1 + 0.1 + 0.1 - 0.3 看似乎很傻，小学生都会，但 Python 可能搞不定，如下图所示，结果是一个非常奇葩的数值……请使用恰当的方式计算出正确的结果。

- 示例数值

  ```python
  >>> 0.1 + 0.1 + 0.1 - 0.3
  5.551115123125783e-17
  ```

- 如何避免 - 使用decimal模块

  ```python
  # -*- coding: utf-8 -*-
  # @Software: PyCharm
  # @Author: Ammoniaw
  # @FileName: correct_calu.py
  # @Date: 2026/8/2
  # @Description: 正确计算浮点数
  import decimal
  
  a = decimal.Decimal('0.1')
  b = decimal.Decimal('0.3')
  # 计算0.1 + 0.1 + 0.1 - 0.3
  result = a + a + a - b
  print(result)  # 0.0
  ```
