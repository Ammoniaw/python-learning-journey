### 0. 请编写代码：使用变量（dpy）存放每年的天数（365），变量（hpd）存放每天的小时数（24），变量（mph）存放每小时的分钟数，变量（spm）存放每分钟的秒数（60），最后计算一年有多少秒，并将结果存放到变量（spy）中

- 示例代码 seconds.py

  ```python
  # -*- coding: utf-8 -*-
  # @Software: PyCharm
  # @Author: Ammoniaw
  # @FileName: seconds.py
  # @Date: 2026/8/1
  # @Description: 使用变量存储时分秒信息
  
  day = 365
  hpd = 24
  mph = 60
  spm = 60
  
  # 计算一年有多少秒
  spy = day * hpd * mph * spm
  print(f"一年(365天)有{spy}秒")  # 一年(365天)有31536000秒
  
  ```
